Accrual Balances

GET

Retrieves the accrual balance of an employee at the current or a specific date. To get the balance on a specific date, include the `asOfDate` query parameter. To get specific time-offs, include the `timeoff` query parameter. The hour(s) value is in milliseconds (ms).

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • asOfDate
    string
    balance date.
  • timeoff
    string
    list of timeoff ids
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

The supplied credentials, if any, are not sufficient to create the resource.

In case of any security issues

POST

Sets the accrual balance for an employee. This operation supports V1 of the Accruals module. To set a specific date for `updated_to_date`, provide a value for the `date` field within the `updated_to_date` object. To set `updated_to_date` to the end of the accrual year, leave the `date` field empty and set `set_to_end_of_accrual_year` to true. The `hours`, `external_accrued`, `external_taken`, and `external_carry_over` fields use HH:MM or HH.DD format.
