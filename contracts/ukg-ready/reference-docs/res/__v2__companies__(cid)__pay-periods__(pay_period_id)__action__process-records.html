Process Records

POST

Allows the caller to execute the 'Process Records' business step in the Pay Prep process. The process is asynchronous and returns a jobid that can be queried to retrieve the status.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id

Responses

If process records job is started, contains the link to retrieve the job status.

  • Location
    string
    required

    Example: <Address>/ta/rest/v2/pay-periods/55237761/functions/process-records/522370

    Location to get the job status for process records.

In case any error occurs during validation.

In case of security errors.

In case the service is unavailable.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/pay-periods/{pay_period_id}/action/process-records
