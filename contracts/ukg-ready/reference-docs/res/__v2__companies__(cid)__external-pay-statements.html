External Pay Statements

Allows a user to create a new Pay Statement and attached document based on information provided by a 3rd party Payroll system.

POST

Allow user to upload their Pay Statements External pay statements upload is a two-phase process. - Step 1: Create Pay Statement and document metadata - Step 2: Get a link to the pay statement content - Step 3: Upload Pay statement's content When Pay Statement and its document metadata is created, you will be provided with a link to the pay statement resource, where you can get a link to a pay statement file content. Functionality is available for companies having "Import External Pay History" functionality enabled .

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required
