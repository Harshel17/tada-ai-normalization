Notification Tags

GET

Endpoint to fetch list of all notification tags.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • event_id
    string
    required

    Example: APPLICANT_COMMUNICATION

    If event_id is present, api will return notification tags.

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/lookup/notification-tags
