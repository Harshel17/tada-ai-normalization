Actions

POST

Executes an Action on a given Schedule Advanced Scheduler (<b>SCHEDULE</b>) Subsystem must be enabled in company setup.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • schedule_id
    integer
    required

    Example: 123456

    Schedule ID
  • action_id
    string
    required

    Example: post,unpost

    Action to perform on the Schedule.

Responses

Action performed.

Returned in case a user has insufficient permissions

Action requested was not to be found

Returned in case the `Accept` header contains media type unsupported by end point

Returned in the event an internal server error occurred while processing the request

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/schedules/{schedule_id}/actions/{action_id}
