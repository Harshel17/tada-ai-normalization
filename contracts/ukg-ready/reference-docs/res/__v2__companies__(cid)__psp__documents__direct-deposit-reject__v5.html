Version 5

POST

Submits an Direct Deposit Reject/Return document from the payment processor. **General Behavior:** - Validates the request body according to the v5 direct-deposit-reject schema - Processes returned direct deposit transactions for employees - Creates a document upload record linked to the company - Returns the document upload name and ID upon successful storage **Security Requirements:** The authentication token must have the required security access: - "Modules > REST API Resources > PSP Documents > Add checkbox" - "Distribution > Distribution > Upload Service Provider Documents checkbox" - Requires "Integrated Document Storage" Marketplace Product **Document Access:** - Uploaded documents will be visible in "Distribution > Tools > Upload Service Provider Documents"

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Document has been accepted and stored successfully. Returns the document upload ID.

Bad request. Possible reasons: - Missing required fields (podId, tenantId, companyId, countryCode, payrollId, payDate, returnEmployees) - Invalid field values (e.g., countryCode must be in ['CAN']) - returnEmployees array is empty - payrollId is not convertible to long integer - payDate is not in ISO-8601 format (YYYY-MM-DD)

Forbidden. User lacks required security permissions.

Internal server error. Document upload creation or storage failed.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/psp/documents/direct-deposit-reject/v5
