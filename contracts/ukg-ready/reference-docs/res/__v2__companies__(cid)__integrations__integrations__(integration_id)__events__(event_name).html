Incoming Webhook Events

<b>Not available for the general use. Available for supported integrations that use Incoming Webhooks.

POST

Endpoint to submit webhook payloads from third party applications to ready API.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • integration_id
    integer
    required
    Integration Id
  • event_name
    string
    required
    Event name
Query Parameters
  • token
    string
    Token required for authentication

Responses

Payload is accepted successfully.

Payload is incorrect.

Request is unauthorized.

Integration or event is not found.

Payload is exceeds the maximum allowed size.
