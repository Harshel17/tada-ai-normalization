Document

GET

Retrieves the metadata of a specified document. There are two types of documents: global documents and attached documents. - An attached document has a reference to a specific resource in the system, such as a timesheet document. - A global document is uploaded by a system administrator and does not have a reference but can be browsed by users in a common place (e.g., Tax Documents, Company Documents). Each returned document contains links to its content with a short expiration time. The response may contain one of the following links: - `content_r` - provides read-only access - `content_rw` - provides read-write access - `content_w` - provides write-only access Refer to the [File Upload/Download](#File_Upload_Download) section for information about the file content upload process. This functionality is available for companies with the "Integrated Document Storage" marketplace product.
