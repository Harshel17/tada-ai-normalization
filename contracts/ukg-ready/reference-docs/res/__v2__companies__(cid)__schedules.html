Scheduler

GET

Returns the list of Schedules Advanced Scheduler (<b>SCHEDULE</b>) Subsystem must be enabled in company setup.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • from
    date-only
    required
    Schedule Date Range filter. (Min date)
  • to
    date-only
    required
    Schedule Date Range filter. (Max date)
  • is_continuous
    boolean
    Schedule is_continuous filter, if set to true, it will always return only schedules with the is_continuous flag set to true. If set to false, when the CONTINUOUS_SCHEDULING feature toggle is enabled, only non-continuous schedules will be returned, however, if the CONTINUOUS_SCHEDULING feature toggle is disabled, then all schedules regardless will be returned without regard to the status of the is_continuous flag. When this parameter is left empty, the behavior will be the same as if the parameter was set to false.
  • settings_id
    integer
    Schedule Base Settings ID filter.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
