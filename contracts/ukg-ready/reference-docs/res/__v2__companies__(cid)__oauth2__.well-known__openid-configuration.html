OpenID Configuration

The OpenID Configuration API is used to retrieve the OpenID Connect configuration details for the authorization server.

GET

The OpenID Configuration endpoint is used to retrieve the OpenID Connect configuration details for the authorization server.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

The request is valid, and the OpenID Connect configuration details are returned in the response body.

Returned in case of any error in the request body.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/oauth2/.well-known/openid-configuration

Response Samples

{
  "issuer": "https://example.com",
  "authorization_endpoint": "https://example.com/oauth2/authorize",
  "token_endpoint": "https://example.com/oauth2/token",
  "subject_types_supported": [
    "public"
  ],
  "id_token_signing_alg_values_supported": [
    "RS256"

}
