Clear error messages

POST

Performs to clear error messages for the specified payrolls.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Clear messages successfully finished.

In case any error occurs during validation.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/payrolls/actions/clear-messages
