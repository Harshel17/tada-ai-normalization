Timesheets

GET

Endpoint to search timesheets for a single employee. To view your own Timesheets, user has to have an "Access Personal Timesheets" permission. Only one of the following parameters is mandatory to fulfil request: - date - current - previous - next

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • date
    string
    Date to find by Account and Date
  • current
    boolean
    mark, to return current timesheet of employee
  • previous
    boolean
    mark, to return previous timesheet of employee
  • next
    boolean
    mark, to return next timesheet of employee
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/timesheets
