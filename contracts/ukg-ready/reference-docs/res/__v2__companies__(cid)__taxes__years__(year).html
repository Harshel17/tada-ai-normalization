Company Tax Year

GET

Return the tax year details

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • year
    integer
    required

    Example: 2019

    the four digit year.
Query Parameters
  • ein_id
    integer

    Example: 907585

    The ein id to get the tax year if a company has multiple eins. It uses the account default ein if not specified.

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/taxes/years/{year}
