Revoke OAuth application.

PUT

Endpoint to revoke OAuth application. To unrevoke application see PUT /v2/companies/{cid}/oauth/applications/{id}

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required

    Example: 1111

    OAuth application id.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required
