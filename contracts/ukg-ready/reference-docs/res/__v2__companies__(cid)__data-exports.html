Data Exports

POST

Creates a new Data Export in the company that a user can run.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string
    required

    Valid values: application/json

    Example: application/json

Responses

Returned in case Data Export created successfully.

Company not found

Returned in case any request validation errors occur.

Returned in case any internal server errors occur.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/data-exports

GET

Retrieves all available Data Exports in the company that the user can run.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string

    Valid values: application/xml, text/xml, */xml, application/json

    Example: application/xml

Responses

Authentication required

Returned in case user has insufficient rights to call the action

Returned in case the `Accept` header contains a media type unsupported by the operation

Returned in the event an internal server error occurred while processing the request

Definition
