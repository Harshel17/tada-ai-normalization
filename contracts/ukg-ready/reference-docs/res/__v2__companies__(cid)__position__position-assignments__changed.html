Position Assignments Changed

GET

Return the information of all the assignment that has been created/modified/deleted in given time frame. <br>API will also enable the consumer to specify what all detail he wants for the assignment. <br>By default only the basic assignment details will be returned.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • since
    datetime

    Example: 2017-09-15T20:55:00Z

    Used to set reference date to determine changes, the value cannot be more than 31 days in the past. <br>Date should be expressed according to ISO 8601. <br>If the timezone is not provided or cannot be parsed the system will default to the timezone of the company. Default value is today minus 5 days.
  • req_details
    string

    Example: all

    A comma separated string of all the details that are required. Possible values to be provided are : <br>1. all -> Will fetch all the details for the assignment <br>2. ccdetails -> Will fetch basic details + cost center details. <br>3. directRepManager -> Will fetch basic details + direct reporting manager details. <br>4. attributes -> Will fetch basic details + extra attributes details. <br>5. rates -> Will fetch rates for the assignment. <br><br>Example : “all”, will fetch all the details. <br>“ccdetails” will fetch basic details and cost center details of the assignment. <br>“attributes, rates, directRepManager” will fetch basic+attributes + rates + direct reporting manager details of the assignment.
  • effective_assignments_only
    boolean

    Example: true

    If set as true, the result set will be filtered to contain only those assignments whose duration overlaps with given duration i.e. (since date - today). <br>If not provided, the default value of this flag is false.
  • page
    integer
    Page number.If not provided the default value will be treated as 1.
  • size
    integer
    Items per page. Max limit is 200 per page. If not provided, then default value will be treated as 50.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
