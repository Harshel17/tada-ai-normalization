Announcements

GET

Retrieves active announcements for users. Requires permission to view announcements, or there must be announcements available to the user based on their security profile and/or group. Requires at least one of the following subsystems: - TLM - HR - HR (Small Business Edition)

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • is_popup
    boolean
    Can be used for getting active announcements configured on Pop Up Communicator and Company levels.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/announcements
