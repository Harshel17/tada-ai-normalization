Marketplace Products

POST

Adds marketplace products to the company by product names.

  • dev

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Marketplace products successfully added.

Bad request.

Company not found.

Internal server error.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/marketplace-products
