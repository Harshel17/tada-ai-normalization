Pay Periods

GET

Allows the caller to retrieve a list of the pay periods, optionally filtered by date and state.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • ein_id
    integer

    Example: 1689

    The ein id to get the pay periods if a company has multiple eins. All pay periods for all eins are returned if not specified. A list of company eins can be fetched using the ein lookup api.
  • date_from
    date-only
    required

    Example: 2016-08-15

    Used for getting pay periods to date lower bounded. The date, six months prior to today's date is used as date_from if not specified.
  • date_to
    date-only
    required

    Example: 2017-02-15

    Used for getting pay periods to date upper bounded. Today's date is used as date_to if not specified.
  • pay_date
    date-only
    required

    Example: 2017-02-15

    Used to filter pay periods by pay date specified. Ignored if it's not present.
  • open
    boolean
    required
    Used to specify whether only open pay periods should be returned that is ones that don't have payroll assigned. Ignored if not present.
  • locked
    boolean
    required
    Used for specifying the type of pay periods to be listed, "true" for all locked pay-periods, "false" for open. All open and locked pay periods are returned if the locked parameter is not specified.

Responses

In case any error occurs during validation.

In case of security errors.

In case the service is unavailable.
