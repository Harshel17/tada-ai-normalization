Timesheet Action

PUT

Endpoint to perform actions on a timesheet. Availability of action depends on a current timesheet state and permission of a user.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    Timesheet ID
  • action_name
    string
    required

    Valid values: SUBMIT, APPROVE, REJECT, REOPEN, CORRECT

    Name of the action to perform
Query Parameters
  • ignore_warnings
    boolean
    If set to 'true', forces API to ignore all warnings produced by timesheet rules.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Timesheet action is successful.

In case timesheet action cannot be performed due to violation of timesheet rules, corresponding error messages will be returned. Response also contains 'user_messages' field that provides user friendly explanation of what is wrong with the data. Warning messages are treated as errors and stops processing. To ignore warnings use 'ignore_warnings' query parameter.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/timesheets/{id}/action/{action_name}
