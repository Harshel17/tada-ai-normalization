Position

GET

Return the details of that position irrespective of whether its active and effective as of today.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • positionId
    string
    required

    Example: 1234567

    Unique Id of a position which can be seen on the edit position screen..
Query Parameters
  • req_details
    string

    Example: all

    A comma separated string of all the details that are required. Possible values to be provided are : <br>1. all -> Will fetch all the details for the position <br>2. ccdetails -> Will fetch basic details + cost center details. <br>3. directRepManager -> Will fetch basic details + direct reporting manager details. <br>4. attributes -> Will fetch basic details + extra attributes details. <br><br>Example : “all”, will fetch all the details. <br>“ccdetails” will fetch basic details and cost center details of the position. <br>“attributes, directRepManager” will fetch basic+attributes + rates + direct reporting manager details of the position.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
