Payroll Export Status

GET

Allows the caller to retrieve the status for payroll export job. If the payroll export is successfully completed the download_link parameter in the response will contain a temporary download link that is valid for 10 minutes. The link contains an encrypted authentication token that allows the file to be downloaded without requiring separate authentication headers, or cookies. The authentication within the link is generated in the context of the user that called the API, the link should not be shared with other users. example : <Address>/ta/fs?ticket=[REDACTED_DOCUMENTATION_TOKEN]

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id
  • job_id
    integer
    required
    Job Id

Responses

In case of security errors.

In case not found.

In case the service is unavailable.
