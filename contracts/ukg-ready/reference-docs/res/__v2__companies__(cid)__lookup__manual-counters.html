Manual Counters

GET

Returns the list of defined counters in the company.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • date
    date-only
    required

    Example: 2016-05-15

    Date of timesheet.
  • owner_id
    integer
    required
    Timesheet owner id.

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/lookup/manual-counters
