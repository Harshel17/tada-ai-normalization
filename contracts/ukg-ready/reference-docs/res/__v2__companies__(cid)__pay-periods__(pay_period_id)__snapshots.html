Snapshots

GET

Allows the caller to retrieve the list of available snapshots for the pay period. Snapshots can be used in the Export Payroll API to define the data that should be included in the resulting Payroll interface file.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id

Responses

In case of security errors.

In case the service is unavailable.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/pay-periods/{pay_period_id}/snapshots
