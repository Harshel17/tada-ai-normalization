System

GET

Endpoint returns list of employee's system forms for a period of time.This endpoint can be accessed by both employees and admin to get pay forms.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • form_types
    string

    Valid values: W2, W4, 1099MISCPRE2020, 1099MISC, 1099NEC, I9, LC2810, WH380E, WH380F, WH381, WH382, WH384, WH385, WH385V, CC305, TFNDECLARATION, SUPERANNUATION, CUSTOMFORMITEM, HMRCSTARTERCHECKLIST, T4, TD1, RL1, ROE

    Form types. If not specified, all types accessible to an employee. Comma separated string for multiple types. <br><b>1099MISCPRE2020</b> - Returns all 1099 MISC forms before year 2020.</br> <br><b>1099MISC</b>- Returns all 1099 MISC form after 2019.</br>
  • created_from
    date-only

    Example: 2016-05-15

    Start date of searching period on form creation date.
  • created_to
    date-only

    Example: 2016-05-15

    End date of searching period on form creation date.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

If date range is not valid or invalid form type.

If there is any security violation.

If company or employee is not found.

Returned in case user is not authorized.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/forms/system
