Anniversary Calendar

GET

Retrieves a list of employee anniversaries within a required date range. The date range must be less than or equal to 366 days. This operation requires one of the following security items: - "Anniversary Calendar" to see anniversaries of all accessible employees. - "Anniversary Calendar (All Company Employees)" to see anniversaries of all company employees. Terminated employees are not included in the calendar by default for any anniversary type, except 'TERMINATED'.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • type
    string
    required

    Valid values: STARTED, BENEFITS, BIRTHDAY, DECEASED, HIRED, PEO_HIRED, REHIRED, RETIRED, REVIEW, SENIORITY, TERMINATED, CUSTOM_DATE_1, CUSTOM_DATE_2, CUSTOM_DATE_3, CUSTOM_DATE_4, CUSTOM_DATE_5

    Example: STARTED

    Employee date, to be considered as anniversary in calendar. It can be hire, termination or any other date.
  • date_from
    date-only
    required

    Example: 2016-01-01

    Start of date range.
  • date_to
    date-only
    required

    Example: 2016-12-31

    End of date range.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
