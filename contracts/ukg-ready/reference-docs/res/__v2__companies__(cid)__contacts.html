Contacts

POST

Creates employee contacts. The fields 'bsn', 'social_insurance', 'social_security', and 'national_insurance' are for backward compatibility; the system uses old processing rules if they are included in the request. The new pattern for national identification numbers is represented by the 'national_id_numbers' field. <b>Note</b>: 'national_id_numbers' is ignored if the request contains any of 'bsn', 'social_insurance', 'social_security', or 'national_insurance'.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

    Example: application/json

    required
