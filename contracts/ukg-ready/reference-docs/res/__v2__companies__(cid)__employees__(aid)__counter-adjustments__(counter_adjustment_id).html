Counter adjustment

PUT

Updates a counter adjustment.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
  • counter_adjustment_id
    string
    required

    Example: 1234567

    Counter adjustment should be referenced via counter adjustment id.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Counter adjustment was successfully updated.

In case any error occurs during validation.

In case of any security issues.

In case the counter adjustment with such an 'id' wasn't found.

Internal server error.

Returned in case user is not authorized.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
