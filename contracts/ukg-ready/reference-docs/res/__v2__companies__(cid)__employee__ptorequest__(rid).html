PTO Request

GET

Endpoint provides information about single time off request.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • rid
    integer
    required
    Time off request id

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employee/ptorequest/{rid}
