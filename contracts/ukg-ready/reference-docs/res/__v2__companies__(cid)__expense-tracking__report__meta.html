Expense Report Metadata

GET

Returns metadata used to create an expense report, including expense tracking profile id and report level attributes.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

No company access

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/meta
