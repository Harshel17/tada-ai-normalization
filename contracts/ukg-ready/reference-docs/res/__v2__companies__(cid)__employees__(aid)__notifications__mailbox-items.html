Mailbox items

GET

Endpoint returns a list of mailbox items in the system for a particular employee.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • created_from
    string

    Example: 2017-04-05T08:00:00Z

    Date to find mailbox items created after the date
  • created_to
    string

    Example: 2017-08-05T08:00:00Z

    Date to find mailbox items created before the date
  • unread
    string

    Valid values: 0, 1

    Example: 1

    Value to find only read or unread mailbox items (1 for unread, 0 for read items)
  • sort
    string

    Valid values: created_at, -created_at

    Example: created_at

    Value to sort items by creation date (if "-created_at" then newer items will be the first)
  • page
    integer

    Example: 1

    Page query parameter for pagination.
  • size
    integer

    Example: 20

    Lot size query parameter for pagination.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/notifications/mailbox-items
