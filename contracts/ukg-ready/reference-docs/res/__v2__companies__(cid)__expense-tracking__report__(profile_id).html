New Expense Report

PUT

Create a new expense report. Ensure the feature is enabled by selecting the Expense Tracking option under `TLM` from the `Edit Company > Available Functionality` page. In addition, the Integrated Document Storage must be added as a Marketplace Product for use with expense reporting.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • profile_id
    integer
    required
    Id of the expense profile used to generate this report. Please refer to the `Expense Report Metadata` endpoint on how to get the profile id and other report metadata.

Responses

Expense report was successfully created

Invalid request

No company access

Expense Profile was not found

Expense Report failed to save

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/{profile_id}
