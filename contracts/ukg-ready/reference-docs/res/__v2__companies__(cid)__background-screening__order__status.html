Order Status

POST

Receives push notifications for Background Screening order statuses.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Returned in case when order status is received successfully.

Returned in case of any error in the request payload.

Returned in case of any error during authentication.

Returned in case of any issue with user rights.

Returned in case of any internal server error.

Returned in case service is temporarily not available.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/background-screening/order/status
