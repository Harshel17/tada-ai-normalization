Announcement statistics

PUT

Updates announcement popup statistics.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • is_close
    boolean
    If the announcement popup was closed by close button.

Responses

Announcement popup statistics was successfully updated.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/announcements/statistics
