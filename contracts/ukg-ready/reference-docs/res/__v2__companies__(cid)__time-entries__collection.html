Batch Update

PUT

Allows to replace all existing time entries for given employee and date range. Maximum date range is __31__ days. __type: EXTRA_PAY__ supports only __date__, __amount__, __from__, __to__ fields. __type: TIME__ supports all fields except __amount__, __from__, __to__. __total__ is ignored when __start_time__ or/and __end_time__ are specified. Time Entry's default values for Cost Centers, Shift Premium, Custom Fields are always overridden. To replace time entries, user must have __DELETE__ and __EDIT__ permissions. Requires at least one of the following subsystems: - TLM - TLM (Small Business Edition: PR/HR Version)

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • partial_update
    boolean

    Example: true

    Use to update entries within the specified time range, instead of replacing them.
