Direct Deposits

POST

__This resource has been deprecated as of April 13, 2023. It will continue to work as per the deprecation policy.__ Creates a new direct deposit account. <p><b>Note:</b> If the calculation method for the new direct deposit is one of: {<b>"GROSS_EARNING", "NET_PAY", "DIRECT_DEPOSIT_PER_OF_REMAINDER"</b>}, the "percentage" property is required. If the calculation method is <b>"FLAT_AMOUNT"</b>, the "amount" property is required.</p>

  • v2
  • deprecated

    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
