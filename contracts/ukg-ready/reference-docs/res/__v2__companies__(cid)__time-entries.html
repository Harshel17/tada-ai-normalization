Time Entries

GET

Allows existing time entries to be fetched for specified company in given date range. Maximum date range of request is 31 days. Response will contain all data that exists in time entry even if they do not displayed on UI due to settings.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • start_date
    date-only
    required

    Example: 2016-05-01

    minimum date of time entry.
  • end_date
    date-only
    required

    Example: 2016-05-30

    maximum date of time entry.
  • is_light
    boolean

    Example: true

    Use light request containing only raw time entry data, no calculated time.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case of success.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/time-entries
