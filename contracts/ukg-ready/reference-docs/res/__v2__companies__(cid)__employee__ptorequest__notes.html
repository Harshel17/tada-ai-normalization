PTO Request Notes

GET

Get all notes for time off request.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • note_thread_id
    integer
    required
Header Parameters
  • Accept
    string

    Valid values: application/xml, text/xml, application/json

    Example: application/xml

Responses

Returned in case invalid query parameters are provided

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employee/ptorequest/notes
