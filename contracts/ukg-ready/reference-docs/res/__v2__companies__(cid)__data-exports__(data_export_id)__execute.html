Execute Data Export

GET

Runs the Data Export specified by the URI parameter `data_export_id`. Returns a relative URL of the created job in the `Location` header and body.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • data_export_id
    integer
    required
    Data Export id
Header Parameters
  • Accept
    string

    Valid values: application/xml, text/xml, */xml, application/json

    Example: application/xml

Responses

  • Location
    string
    required
    Relative URL of the created job.

Authentication required.

Specified Data Export not found

Returned in case user has insufficient rights to call the action.

Returned in case the `Accept` header contains a media type unsupported by the operation.

Returned in the event an internal server error occurred while processing the request.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/data-exports/{data_export_id}/execute

POST

Runs the Data Export specified by the URI parameter `data_export_id`. This operation allows overriding certain settings defined within the export definition by passing a JSON body of key-value pairs. For instance, in the EverythingBenefits Data Export, the `EmpsToUse` parameter can be overridden by providing the parameter name as the key and a comma-separated list of account IDs as the value, e.g., `"EmpsToUse":"123,234,345"`.
