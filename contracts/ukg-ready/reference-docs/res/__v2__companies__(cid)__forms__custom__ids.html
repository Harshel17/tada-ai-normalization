Custom

GET

Endpoint returns available custom forms list. Also, there is an opportunity to include items to the response.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • include_items
    boolean

    Example: true

    Allows include Custom forms items to the response.
  • created_from
    date-only

    Example: 2016-03-14

    Used for getting custom form items from date lower bounded. Should be in `yyyy-mm-dd` format.
  • created_to
    date-only

    Example: 2016-10-31

    Used for getting custom form items to date upper bounded. Should be in `yyyy-mm-dd` format. Maximum difference between `from` and `to` dates can be 60 days.
  • state
    string

    Valid values: NEW, EMPLOYEE_COMPLETED, VERIFIED, COMPLETED, APPLICANT_COMPLETED

    Example: VERIFIED

    Used for getting custom form items that has state in specified range.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned if date range is invalid.

Returned if account is not found.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/forms/custom/ids
