Accrual Balances

GET

Retrieves the accrual balance of an employee for the current period or as of a specific date. The hour(s) value is in milliseconds (ms).

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • asOfDate
    date-only

    Example: 2024-01-01

    Can be used to fetch balances as of date.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

PUT

Applies a change to an employee's remaining accrual balance. To add, set, or deduct from the change remaining, set the `period_date` to select the category period to update. If the action generates any warnings, they are sent to the client, and the operation is not committed. If the user resends the request with the `ignore_warning` parameter set to true, the change is committed, and an empty response with code 204 is returned. fields: "hours": Value for an Hours type accrual category expressed as total milliseconds.
