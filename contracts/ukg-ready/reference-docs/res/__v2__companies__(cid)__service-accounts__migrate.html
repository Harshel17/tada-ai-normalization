Migrate

PUT

Migrate from regular account to service account.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Service Account was successfully migrated.

Account not found.

Internal server error

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/service-accounts/migrate
