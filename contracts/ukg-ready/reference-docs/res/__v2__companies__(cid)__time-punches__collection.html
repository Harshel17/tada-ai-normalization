Time Punches

POST

Endpoint for import punches The Time Punches APIs use a separate security profile item to control access rights which is located in the company security profile in the following location: 1. `Modules -> REST API Resources -> Time Punches -> Edit`. For integration flow the following Cost Center validations are ignored: Employee 'Cost Centers Limit', Cost Center 'Visibility' setting, Cost Center 'Allow Time Allocation' setting, Cost Center Trees 'Used' setting on Company Setup level.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • allow_missing_accounts
    boolean
    If set to 'false', an error will be returned if an account cannot be found, punch will not be recorded. If set to 'true', punches will be recorded but not processed if an account cannot be found.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Returned in case payload was successfully processed. Note: each separate item in the payload may contain errors. Refer to the corresponding error code table and response schema.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the size of the payload exceeds defined limits. Refer to the Restrictions section for details.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
