Ready Learning Items

POST

Allows learning items (Course/Curricula) to be created.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Learning items created successfully.

Bad Request, In case any error occurs during validation.

Unauthorized.

Forbidden, In case of any security issues.

Returned if the resource is not found.

Internal Server Error.

In case the service is unavailable.
