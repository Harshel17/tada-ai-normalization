Payrolls

GET

Endpoint to fetch list of company payrolls normally accessed to process payroll. Date range should be less then year.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • pay_date
    string

    Example: 2016-03-14

    Used for getting payrolls with specified pay date. The value is the absolute pay date of the payroll. When no value is specified, a date range spanning the current date and one year in the past is used. The default value of this parameter is conditional on the value of the start_date and end_date parameters. If either is provided on the request, then no default value is used for pay_date and the field will not be used when fetching available payrolls.
  • pay_date_from
    string

    Example: 2016-03-14

    Used for getting payrolls with pay date after specified date. This parameter may not be used with pay_date one.
  • pay_date_to
    string

    Example: 2016-03-14

    Used for getting list of payrolls to date upper bounded.
  • start_date
    date-only

    Example: 2016-03-14

    Used for getting payrolls with a specific payroll pay period start date. The value is the absolute value of the start date of the payroll.
  • end_date
    date-only

    Example: 2016-10-31

    Used for getting payrolls with a specific payroll pay period end date. The value is the absolute value of the start date of the payroll.
  • status
    string

    Example: OPEN

    Used for getting payrolls according to specified status(NEW, OPEN, CLOSED, SUBMITTED, FINALIZED, OPEN_FAILED, CLOSE_FAILED, ROLLBACK_FAILED, FINALIZE_FAILED).
  • type
    string

    Example: 123456,15487

    Used for getting payrolls of specified type.
  • ein_id
    integer

    Example: 123456

    Used for getting payrolls that belong to specific ein.

Endpoint to create a new payroll that has not been scheduled. Based on company setting several payrolls types are supported: Historical, Regular, Void & etc. To see available types for your company use /lookup{cid}/payroll-types.

    string
    required

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Payrolls successfully saved.

    string
    required
    Location of the newly created payroll.
