Inventory Item

GET

End point to fetch specific employee inventory item by id. Requires at least one of the following subsystems: - HR - HR (Small Business Edition) - EverythingBenefits marketplace product

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    Id to locate the inventory profile.
  • item_id
    integer
    required
    Id to locate the employee inventory item.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned when requested employee inventory item was not found.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/inventory-profiles/{id}/inventory-items/{item_id}
