Cost Centers

GET

Retrieves existing cost centers as a flat list. Relationships can be traced using the `parent_id` field. The root node does not have a `parent_id` field. All visible cost centers are returned, even if their parent has `visible` set to false. Requires 'Cost Center Definitions view' permission to view cost centers. Requires at least one of the following subsystems: - TLM - TLM (Small Business Edition: PR/HR Version) - HR - HR (Small Business Edition) - Payroll - Scheduler

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • tree_index
    integer
    required

    Example: 3

    Tree index must be greater than or equal to 0 and less than or equal to 8.
  • name
    string

    Example: cost center

    The name of cost center.
  • external_id
    string

    Example: cc_external_id_0_126

    The external id of cost center.
  • payroll_code
    string

    Example: 683

    The payroll code of cost center.
  • location_code
    string

    Example: 586

    The location code of cost center.
  • visible
    boolean

    Default: true

    Example: true

    Whether cost center is visible or not.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/config/cost-centers
