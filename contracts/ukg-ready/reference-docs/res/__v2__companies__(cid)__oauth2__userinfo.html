Userinfo

The Userinfo endpoint is used to retrieve user information based on the OAuth 2.0 / OpenID Connect UserInfo endpoint specification. This endpoint requires a valid access token to be provided in the Authorization header. This endpoint requires a valid scope to be provided in the scope.

GET

Retrieves user information for the authenticated user. The response includes various user attributes such as name, email, username, and locale, depending on the user's permissions.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Authorization
    string
    required

    Example: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

    The access token obtained from the OAuth 2.0 authorization process. The token must be included in the Authorization header as a Bearer token.

Responses

The request is valid, and the user information is returned in the response body.

The request is valid, but the user does not have the necessary permissions to access the resource.

Returned in case the access token is invalid or expired or missing authentication.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/oauth2/userinfo
