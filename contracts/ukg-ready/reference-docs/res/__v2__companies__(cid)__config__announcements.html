Announcements

GET

Retrieves announcement configurations. Requires permission to view announcements. Requires at least one of the following subsystems: - TLM - HR - HR (Small Business Edition)

  • dev

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • active
    boolean
    Can be used for getting active announcements.
  • active_from
    date-only

    Example: 2016-03-14

    Can be used for getting active from date lower bounded announcements.
  • end_date
    date-only

    Example: 2016-10-31

    Can be used for getting active to date upper bounded announcements.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition
