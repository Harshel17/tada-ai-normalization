Expense Item Summaries

GET

Returns summaries for all items on the expense report

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • report_id
    integer
    required
    Id of the expense report

Responses

No company access

Expense report not found

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/{report_id}/item-summaries
