Introspect

The Token Introspection API allows resource servers to query an authorization server to determine the state and metadata of an OAuth token.

POST

The OAuth Token Introspection API allows resource servers to verify the status and details of an OAuth token by querying the authorization server.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Content-Type
    string
    required

    Example: application/x-www-form-urlencoded

  • Authorization
    string
    required

    Example: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

    The access token obtained from the OAuth authorization process. The token must be included in the Authorization header as a Bearer token.

Responses

The request is valid, and the token is introspected successfully. The response includes the status and metadata of the token.

The request is invalid, and the token is not introspected. The response includes an error message.

The request is valid, but the token is not introspected because the bearer access token is invalid or expired.

The request is valid, but the token is not introspected because the client does not have the necessary permissions to access the resource.

The request is valid, but the token is not introspected because of an internal server error.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/oauth2/introspect
