Expense Type Metadata

GET

Returns expense type metadata used to add expense item to an expense report, including all expense types and their attributes supported by the expense report.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • report_id
    integer
    required
    Id of the expense report

Responses

No company access

Expense report not found

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/{report_id}/meta
