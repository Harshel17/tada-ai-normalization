Get/Update/Delete Expense Item

GET

Returns specified expense item

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • report_id
    integer
    required
    Id of the expense report
  • item_id
    integer
    required
    Id of the expense item

Responses

No company access

Expense item not found

Definition

    integer
    required
    Id of the expense report
  • item_id
    integer
    required
    Id of the expense item
