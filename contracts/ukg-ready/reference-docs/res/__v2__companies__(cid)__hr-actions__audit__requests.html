HR Action Audit Requests

Enables the creation and retrieval of HR Action Audit Requests. These requests are essential for generating data for the Future Dated HR Actions report, which allows users to view future effective-dated changes for approved HR action requests.

GET

Retrieves a list of HR Action Audit Requests.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • page
    integer
    Page number.
  • size
    integer
    Items per page.
  • sort
    string
    Used to sort HR Action Audit Requests. Available value is `created`. Descending order is established by adding `-` before column name.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Successfully retrieved the list of HR Action Audit Requests.

Returned in case resource does not exist.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/hr-actions/audit/requests
