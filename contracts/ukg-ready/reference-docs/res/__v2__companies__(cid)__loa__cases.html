Cases

GET

Endpoint for fetching leave of absence cases. Leave of absence functionality must be enabled in company. Provides only basic data for each case.

POST

Endpoint for creating new leave of absence case. Leave of absence functionality must be enabled in company. This endpoint doesn't support any kind of leave of absence entries generation, case auto-closing or any other actions. `status` can be only open or not pointed at all. `sub_status` and `resolution` are read-only fields. `case_number` can be required or not, depending on employee leave of absence profile settings. Custom fields also can be required depending on leave of absence profile. Indexing starts from `0` due to selected order in leave of absence profile. If you specify `continuous` type for `leave_time` you must also specify `total_time_type` and if it is `custom`, then `total_time` must be provided. If you specify `intermittent` type for `leave_time` you must also specify `intermittent_type`,`frequency`, `frequency_interval`, `frequency_interval_type` and `total_time`. If you specify `weekday` type for `leave_time` you must also specify `weeks_in_cycle`, and `weekdays`. If `use_separate_settings` is set to false, each element in `weekdays` must have the same properties as others. All totals must be provided in ms (not more than standard working hours). See schemas for detailed information about accepted values.
