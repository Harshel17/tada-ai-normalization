Recalculate company taxes

POST

Recalculates the W2, 1099 and pay statement information for the specified tax year. This starts a job. See the location header for information on retrieving the job status. Requires the following subsystems: - PR

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • year
    integer
    required

    Example: 2019

    the four digit year.
Query Parameters
  • ein_id
    integer

    Example: 907585

    The ein id to get the tax year if a company has multiple eins. It uses the account default ein if not specified.
  • calcW2s
    boolean

    Example: false

    Boolean indicating that W2 forms should be recalcuated
  • calc1099s
    boolean
    Boolean indicating that 1099 forms should be recalcuated
  • calcT4s
    boolean
    Boolean indicating that T4 forms should be recalcuated
  • calcRL1s
    boolean
    Boolean indicating that RL-1 forms should be recalcuated

Responses

The action was accepted a job was started.

  • Location
    string
    required
    URL to retrieve job status.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/taxes/years/{year}/actions/recalculate
