Contacts

GET

Endpoint to get list of employee contacts.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • page
    integer
    Page number.
  • size
    integer
    Items per page.
  • sort
    string
    Used to sort account contacts. Available values are `contact_name`, `relationship`, `primary`. Descending order is established by adding `-` before column name.
  • contact_type
    string

    Valid values: EMERGENCY, DEPENDENT, BENEFICIARY

    Used to fetch account contacts filtered by contact type.
Header Parameters
  • X-User-Profile-Type
    string
    Identifies the type of view for the account profile : applicant or employee. By default employee profile view is used for the account.
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/contacts
