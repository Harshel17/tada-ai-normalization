Time Off Calendar Sync

GET

Endpoint to sync time off calendar for an employee to a personal calendar.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • syncToken
    string
    required

    Example: f1acb6534b1e4b3e8b3e8b3e8b3e8b3e

    Calendar Sync token.

Responses

Forbidden - Security violation.

Not Found - Company not found.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/timeoff-calendar-sync
