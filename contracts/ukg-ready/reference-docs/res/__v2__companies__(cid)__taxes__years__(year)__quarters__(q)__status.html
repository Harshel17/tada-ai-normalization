Company tax quarter status

PUT

Endpoint updates the status of the tax quarter with the given number. Requires the following subsystems: - PR

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • year
    integer
    required

    Example: 2019

    the four digit year.
  • q
    integer
    required

    Example: 1

    The quarter number. (1 - 4)

Responses

The status was successfully updated.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/taxes/years/{year}/quarters/{q}/status
