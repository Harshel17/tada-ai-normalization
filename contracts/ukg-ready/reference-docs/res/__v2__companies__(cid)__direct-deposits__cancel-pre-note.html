Cancel Pre Note

PUT

__This resource has been deprecated as of April 13, 2023. It will continue to work as per the deprecation policy.__ Cancels the pre-note for selected direct deposits.

  • v2
  • deprecated

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • X-End-of-Support-Timeline
    string
    required

    Default: 2026-01-29

Responses

Cancel pre-note has been applied successfully.

Cancel pre-note has failed.
