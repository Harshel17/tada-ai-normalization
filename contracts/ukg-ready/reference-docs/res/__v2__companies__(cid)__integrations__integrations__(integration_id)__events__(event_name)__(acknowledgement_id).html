Incoming Webhook Events Acknowledgement

<b>Not available for the general use. Available for supported integrations that use Incoming Webhooks.

GET

Retrieves the current processing status for an event identified by its unique acknowledgementId.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • integration_id
    string
    required
    Integration ID
  • event_name
    string
    required
    Name of the event
  • acknowledgement_id
    string
    required
    A unique UUID returned when the event was initially acknowledged by the webhook.
Query Parameters
  • token
    string
    required
    Token required for authentication

Responses

Successfully retrieved event status

Invalid acknowledgementId format (not a UUID).

Request is unauthorized.

Integration or event is not found.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/integrations/integrations/{integration_id}/events/{event_name}/{acknowledgement_id}
