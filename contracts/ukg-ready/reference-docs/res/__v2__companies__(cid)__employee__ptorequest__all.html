All PTO Requests

GET

Endpoint to list PTO requests for subordinate employees. `TA|TALITE|HR` functionality must be enabled in company setup.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • fromDate
    string
    pto request date date range start
  • toDate
    string
    pto request date date range end
  • acc_ids
    string

    Example: 123,432,5366,22145

    IDs of employees which you want to choose
  • ext_ids
    string

    Example: 123,432,5366,22145

    External_IDs of employees which you want to choose
  • user_names
    string

    Example: mgellar

    User names of employees which you want to choose
  • sort
    string

    Example: -from_date

    Query parameter to control sorting order. Default is descending by requested date. Supported fields to sort by: - `from_date`

Responses

Contains filtered list of PTO requests

Unauthorized, Authentication is required

Not found, Account was not found

Required functionality is not enabled

Returned in the event an internal server error occurred while processing the request.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employee/ptorequest/all
