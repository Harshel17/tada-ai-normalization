Logout

The OAuth logout API is used to end the session and log out the user associated with the Token. The token should belong to the user and should not be issued by Client Credentials flow.

GET

The logout endpoint is used to log out the user associated with the access token.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Authorization
    string
    required

    Example: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

    The access token obtained from the OAuth 2.0 authorization process. The token must be included in the Authorization header as a Bearer token.
  • post_logout_redirect_uri
    string

    Example: https://example-redirect-uri.com/logout

    The URL to which the user will be redirected after logging out. This URL must be registered with the authorization server.

Responses

The request is valid and the user is logged out successfully.

The request is valid and the user is redirected to the post_logout_redirect_uri.

The request is valid, but the user does not have the necessary permissions to access the resource.

Returned in case the access token is invalid or expired or missing authentication.

Returned in case of any error during the logout process.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/oauth2/logout
