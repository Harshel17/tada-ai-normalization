Direct Deposits

GET

__This resource has been deprecated as of April 13, 2023. It will continue to work as per the deprecation policy.__ Endpoint returns list of employee's direct deposit accounts.

  • v2
  • deprecated

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • page
    integer
    Page number.
  • size
    integer
    Items per page.
  • sort
    string
    Used to sort checklists. Available values are `type`, `active_from`, `active_to`, `account_number`, `account_type`. Descending order is established by adding `-` before column name.
  • active
    boolean
    Used to fetch only active direct deposits.
Header Parameters
  • X-End-of-Support-Timeline
    string
    required

    Default: 2026-01-29

  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/direct-deposits
