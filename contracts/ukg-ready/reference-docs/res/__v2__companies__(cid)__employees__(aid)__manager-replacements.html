Manager Replacements

GET

Endpoint for fetching employee Manager Replacements. The Employee APIs use a separate security profile item to control access rights which is located in the company security profile in the following location: 1. `Modules -> REST API Resources -> Employees -> View`. 2. `Modules -> REST API Resources -> Employees -> ESS View`. <b>Only the 'REST API RESOURCES' security profile items in combination with 'manager permissions' are considered by this REST API resource.</b>

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/manager-replacements
