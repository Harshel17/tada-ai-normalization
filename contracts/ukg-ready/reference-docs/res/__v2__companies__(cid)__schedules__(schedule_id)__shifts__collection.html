POST

Bulk operation to create multiple Shifts Advanced Scheduler (<b>SCHEDULE</b>) Subsystem must be enabled in company setup.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • schedule_id
    integer
    required

    Example: 123456

    Schedule ID
Query Parameters
  • create_change_request
    boolean
    To explicitly confirm that a change request must be created if necessary

Responses

ALL shifts were created.

Returned in case a user has insufficient permissions

Referred Schedule was not found

Returned in case the `Accept` header contains media type unsupported by end point

Returned in the event that the size of the payload exceeds defined limits. Refer to the Restrictions section for details.

Returned in the event an internal server error occurred while processing the request
