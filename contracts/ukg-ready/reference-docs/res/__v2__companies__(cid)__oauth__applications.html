OAuth Applications

GET

Gets all OAuth applications available within the company. If `application_type.type` is equal to "Machine to Machine" and company is a client company then `company_group_ids`, `login_as_account` and `login_as_sa` will not be returned in response. If `application_type.type` is equal to "Interactive" then `account_group_ids`, `security_profile`, `allow_edit`, `company_group_ids`, `login_as_account` and `login_as_sa` will not be returned in response. `redirect_url_whitelist` will be returned only for "Interactive" application type. It is returned as a single string with comma separated entries (i.e. "/one/two,/three/four").

POST

Allows a new OAuth application to be created. `application_type.type` can be either "Interactive" or "Machine to Machine". Once set application type cannot be changed later. If `application_type.type` is equal to "Machine to Machine" then additional fields are mandatory: `secret`, `security_profile` and `account_group_ids`. If `application_type.type` is equal to "Machine to Machine" and company is a Partner company then `company_group_ids` is mandatory as well. If `application_type.type` is equal to "Interactive" then `redirect_url_whitelist` is mandatory. It should be send as a single string with comma separated entries (i.e. "/one/two,/three/four").
