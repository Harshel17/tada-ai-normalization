GET

Retrieves a list of Base Compensation entries for all subordinates. Each item contains a reference to a detailed resource.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

POST

Creates an Employee Base Compensation entry. The `auto_pay` field is processed only for companies with the Payroll subsystem.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Request has been created successfully.

  • Location
    string
    required
    Location of the newly created Employee Base Compensation.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
