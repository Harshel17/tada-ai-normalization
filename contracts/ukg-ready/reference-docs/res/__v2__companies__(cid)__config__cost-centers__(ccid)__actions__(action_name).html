Cost Center Action

PUT

Performs an action on a Cost Center. Requires a 'Cost Center Definitions edit' permission. The "MOVE" action sets a new Parent for the Cost Center. Requires at least one of the following subsystems: - TLM - TLM (Small Business Edition: PR/HR Version) - HR - HR (Small Business Edition) - Payroll - Scheduler

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • ccid
    integer
    required

    Example: 45

    The id of cost center.
  • action_name
    string
    required

    Valid values: MOVE

    Name of the action to perform
