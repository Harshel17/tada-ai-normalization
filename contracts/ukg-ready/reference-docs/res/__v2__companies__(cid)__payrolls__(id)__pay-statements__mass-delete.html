Pay Statement Mass Delete

POST

Delete multiple pay statements via a key_set_ref or list of pay statement ids

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    Payroll id.

Responses

Pay Statements successfully deleted.

Company, payroll or pay statement ids not found. See error text for more info.

Individual pay statement not found or access forbidden. See error text for more info.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/payrolls/{id}/pay-statements/mass-delete
