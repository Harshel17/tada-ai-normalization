External PayStatements

GET

Allow user to get Pay statement data. The pay statement returned contains a links to its content. Link has a short expiration time. Response may contains one of the following links: - `content_r` - link provides read-only access - `content_rw` - link provides read-write access - `content_w` - link provides write-only access Please refer to [this](#File_Upload_Download) section to get information about file content upload process. Functionality is available for companies with "Import External Pay History" functionality enabled.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pst_id
    integer
    required
    ID of external PayStatement.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

If there are no any handlers for specified type.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/external-pay-statements/{pst_id}
