Asset Assignment Action

PUT

Performs an action on an asset assignment, such as marking it as returned, lost, or destroyed. Requires at least one of the following subsystems: - HR - HR (Small Business Edition)

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    The unique identifier for the asset assignment.
  • action_name
    string
    required

    Valid values: RETURNED, LOST_DESTROYED

    Name of the action to perform
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Asset assignments were processed

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/asset-assignments/{id}/action/{action_name}
