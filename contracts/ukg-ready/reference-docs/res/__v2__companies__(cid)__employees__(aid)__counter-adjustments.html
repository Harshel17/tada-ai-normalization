Counter adjustments

GET

Allows existing counters to be fetched for a specified account in a given date range. The maximum date range of the request is 31 days.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • start_date
    date-only
    required

    Example: 2016-05-01

    The minimum date of the adjustment's creation.
  • end_date
    date-only
    required

    Example: 2016-05-30

    The maximum date of the adjustment's creation.

Responses

In case any error occurs during validation.

In case of any security issues.

Internal server error.
