Initiate

POST

Endpoint to initiate one or more payrolls.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/payrolls/actions/initiate
