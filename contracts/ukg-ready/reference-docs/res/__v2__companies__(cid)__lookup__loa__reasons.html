LOA Reasons

Leave of Absence Reasons

GET

Returns the list of defined leave of absence reasons in the company.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • account_id
    integer

    Example: 111

    Parameter account for which we should find reasons

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/lookup/loa/reasons
