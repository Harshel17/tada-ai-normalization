Pay Period

GET

Allows the caller to retrieve specific pay period by id.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id

Responses

In case any error occurs during validation.

In case of security errors.

In case the service is unavailable.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/pay-periods/{pay_period_id}
