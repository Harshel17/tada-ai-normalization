Token

OAuth 2.0 is an industry standard authentication protocol that is used for providing access to resources over HTTP. <br><br>The OAuth 2.0 spec has four important roles: <ul> <li>authorization server: The server that issues the access token.</li> <li>resource owner: Normally your application's end user that grants permission to access the resource server with an access token.</li> <li>client: The application that requests the access token from the authorization server</li> <li>resource server: Accepts the access token and must verify that it's valid.</li> </ul> For the purposed of this API guide the authorization server, resource owner and resource server are all the served by this application. Usage of the authorization server for securing 3rd party resource servers is out of scope of this documentation. <br>Supported grant_type values: client_credentials, authorization_code, refresh_token. <br><b>client_credentials</b> required parameters: client_id, client_secret <br><b>authorization_code</b> required parameters: client_id, code, code_verifier, redirect_uri <br><b>refresh_token</b> required parameters: client_id, refresh_token

POST

Implements The OAuth 2.0 Authorization Framework Authorization Endpoint <a href="https://www.rfc-editor.org/rfc/rfc6749#section-4.4" target="_blank">rfc6749 section-4.4 <i class="fa fa-external-link" aria-hidden="true"></i></a>
