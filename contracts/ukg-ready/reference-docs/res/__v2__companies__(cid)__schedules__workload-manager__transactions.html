Workload Manager

POST

Provides the ability to send volume data to Scheduler. Creates workload coverage and open shifts based on volume data sent. Advanced Scheduler (<b>SCHEDULE</b>) Subsystem must be enabled in company setup. <b>Workload Manager</b> functionality must be enabled as well.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Returned in case when the request body violates the schema

Returned if user has insufficient permissions or required functionality is not enabled in the company

Returned if schedule or company specified was not found

Returned if internal server error occurred while processing the request

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/schedules/workload-manager/transactions

DELETE

Provides the ability to delete volume data, workload coverage and generated open shifts from a schedule. Advanced Scheduler (<b>SCHEDULE</b>) Subsystem must be enabled in company setup. <b>Workload Manager</b> functionality must be enabled as well.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • schedule_id
    integer
    required

    Example: 123456

    Schedule Id

Responses

Returned if data was successfully removed

Returned if the required schedule id is not passed as a query parameter

Returned if user has insufficient permissions or required functionality is not enabled in the company

Returned if schedule or company specified was not found

Returned if internal server error occurred while processing the request

Definition

delete {{ getUriPrefix() }}/v2/companies/{cid}/schedules/workload-manager/transactions
