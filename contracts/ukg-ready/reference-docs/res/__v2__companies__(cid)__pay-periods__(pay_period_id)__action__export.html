Export Payroll

POST

Allows the caller to trigger the generation of the payroll interface file. The process is asynchronous so a successful call will return a jobid that can be used to retrieve the status. The body of the request varies depending on the data to be exported, either the current processed results, a given snapshot or a delta. If no snapshot details are provided, the current pay prep results are used to export data. If snapshot data is provided, it should contain either a specific snapshot id or delta snapshot details, but not both at the same time. Refer to the description in the schema for details.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id

Responses

If payroll export job is created, contains the link to fetch the job status.

  • Location
    string
    required

    Example: <Address>/ta/rest/v2/companies/444545/pay-periods/55235777/action/export/522817

    Location to get the job status for process records.

In case any error occurs during validation.

In case of security errors.

In case the service is unavailable.
