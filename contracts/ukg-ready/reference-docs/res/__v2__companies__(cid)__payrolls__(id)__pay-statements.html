Pay Statements

GET

Get information about all payroll pay statements.

  • v2

    required

    integer
    required
    Payroll id.

POST

Endpoint to create new pay statement with provided type for a given employee, allows to enter complex data entry. Currently several pre-defined pay statement types such as `3rd Party Sick`, `Bonus`, `Void`, `Regular`, `Historical` are used for particular payroll. Pay Statement Types provides you with the ability to define the criteria to be used each time a particular Pay Statement Type is utilized during payroll processing. For example, Regular is used for processing a regular payroll, 3rd Party Sick is used for processing the updates of sick pay paid by a third party, and Historical is used for processing historical updates to employee records.
