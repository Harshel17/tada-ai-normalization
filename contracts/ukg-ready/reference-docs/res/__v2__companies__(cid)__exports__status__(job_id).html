Job Status

GET

Endpoint to get current export status. Returns the link to download the file in the `Location` header, if status is DONE.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • job_id
    integer
    required
    Job Id

Responses

  • Location
    string
    required
    Link to download file.

Authentication required

Returned in case user has insufficient rights to call the action

Specified Data Export Status not found

Returned in case the `Accept` header contains media type unsupported by end point

Returned in the event an internal server error occurred while processing the request.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/exports/status/{job_id}
