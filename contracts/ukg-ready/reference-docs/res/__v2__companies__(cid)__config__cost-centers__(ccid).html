Cost Center

GET

Retrieves an existing cost center. The root node has only `id` and `name`. | Property | Comment |-------------|-------------------------------------------- | cost center | TLM, TLM (Small Business Edition: PR/HR Version), HR, HR (Small Business Edition), Payroll, Scheduler subsystem must be enabled in company setup and user must have a Cost Center Definitions view permission. | gl codes | Requires Payroll subsystem. | job settings| Requires Payroll subsystem and user must have a Cost Center Trees view permission. | job strain | Requires TLM, HR, Scheduler subsystem and user must have a Cost Center Trees view permission. | use employee home address| User must have a Cost Center Trees view permission. | work site fields| Requires Payroll subsystem.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • ccid
    integer
    required

    Example: 45

    The id of cost center.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

DELETE

Deletes a cost center by marking it as deleted (soft delete). Business rules: - User must have DELETE_COST_CENTER permission - Root cost centers cannot be deleted (they represent the company's top-level hierarchy) - Cost centers with children must have children reassigned or deleted first - User must have appropriate subsystem access (TA, TALITE2, HR, HRLITE2, PR, PR_CANADA, SCHEDULE) - User must have ACL permissions to access the cost center - Cost center must belong to the user's company
