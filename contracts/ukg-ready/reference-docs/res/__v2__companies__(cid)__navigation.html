Navigation

GET

Provides the hierachy of navigation links available to the user based on security and enabled features.

  • dev

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.

Responses

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/navigation
