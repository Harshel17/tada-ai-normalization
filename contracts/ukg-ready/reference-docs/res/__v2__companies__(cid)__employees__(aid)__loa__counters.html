Counters

GET

Endpoint for fetching employee's leave of absence. Leave of absence functionality must be enabled in company.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • q
    string

    Example: moelle

    Free text search filter for leave of absence counters. Searches against the field `category`. Example: `q=moelle` filters counters whose category contains the word "moelle".
  • sort
    string

    Example: category

    Used to sort leave of absence counters. Available values are category, taken, taken_as_of, entitlement, entitlement_as_of, balance. Descending order is established by adding - before column name.
  • page
    integer

    Example: 1

    Page query parameter for pagination.
  • size
    integer

    Example: 20

    Lot size query parameter for pagination.
  • only_editable
    boolean

    Example: true

    If `true` only editable counter would be returned. `false` by default.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/loa/counters

    required

    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.

Responses
