Expense Reports

GET

Returns specified expense reports based on query parameters

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • submitted_range_start_date
    date-only
    required
    Date to search from (inclusive, max date range = 90 days)
  • submitted_range_end_date
    date-only
    required
    Date to search to (inclusive, max date range = 90 days)
  • created_range_start_date
    date-only
    required
    Date to search from (inclusive, max date range = 90 days)
  • created_range_end_date
    date-only
    required
    Date to search to (inclusive, max date range = 90 days)
  • employee_ids
    string

    Example: 2206081,2206082

    List of employee ids to filter by
  • report_ids
    string

    Example: 2206081,2206082

    List of report ids to filter by
  • offset
    integer

    Example: 1

    Offset query parameter for pagination.
  • size
    integer

    Example: 1

    Lot size query parameter for pagination.

Responses

No company access

Date range is invalid

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/reports
