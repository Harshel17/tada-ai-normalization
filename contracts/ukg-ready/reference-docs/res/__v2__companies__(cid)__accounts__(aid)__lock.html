Lock

PUT

Endpoint provides ability to lock an account.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.

Responses

Returned in case an account was successfully locked.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/accounts/{aid}/lock

DELETE

Endpoint provides ability to delete accounts's lock. During unlock you can reset user's password and TOTP Authenticator.

  • v2

Parameters

Path Parameters

    required

  • aid

    required

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.

Responses

Returned in case an account was successfully unlocked.

Returned in case user has no access to the resource.

Returned in case resource does not exist.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition
