Employee Documents

Get documents for an employee.

GET

Endpoint for receiving list of uploaded documents for an employee. Each object represents a metadata of a single uploaded file. Basically there are two types of documents - global documents and attached documents. - Attached document has a reference to a specific resource in the system. E.g. timesheet documents. When user attaches document to his timesheet, that document maintains relationship with the timesheet. - Global document is a document uploaded by a system administrator that do not have any reference, but can be browsed by users through a common place (e.g. Tax Documents, Company Documents). Each returned document contains a links to its content. Link has a short expiration time. Response may contains one of the following links: - `content_r` - link provides read-only access - `content_rw` - link provides read-write access - `content_w` - link provides write-only access Please refer to [this](#File_Upload_Download) section to get information about file content upload process. Functionality is available for companies with "Integrated Document Storage" marketplace product.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • aid
    string
    required

    Example: 1234567

    Account should be referenced via account id or account external id using `|external_id` or `!external_id` format.
Query Parameters
  • types
    string

    Valid values: TIMESHEET_DOCUMENT, TIME_OFF_DOCUMENT_V2, HR_EMPLOYEE_DOCUMENT, HR_APPLICANT_RESUME, BENEFIT_REQUEST_DOCUMENT, ACCOUNT_DIRECT_DEPOSIT, HR_ACTION_REQUEST_DOC_UPLOAD, HR_ACCOUNT_CHECK_LIST, HR_CHECK_LIST_ITEM, CUSTOM_FORM, DISCIPLINE_INCIDENT, LEAVE_OF_ABSENCE_CASE, LEAVE_OF_ABSENCE_REQUEST

    Types of uploaded documents. If not specified, all types accessible to an employee. Comma separated string for multiple types.
  • created_from
    date-only

    Example: 2022-06-18

    Start date of searching period on document creation date
  • created_to
    date-only

    Example: 2022-06-28

    End date of searching period on document creation date.
  • sort
    string

    Example: sort=display_name,-created_at

    For sorting documents. Comma separated string of fields below with + (optional) for ascending order and - for descending order.<br/><br/> - id: document Id<br/> - type: type of uploaded document<br/> - display_name: display name<br/> - document_type: company defined document type<br/> - file_name: file name<br/> - file_date: last uploaded date<br/> - file_size: file size<br/> - created_at: document creation date<br/> - created_by: last name of document creator<br/>
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

If date range is not valid or there are no any handlers for specified type.

If there is any security violation.

If company or employee is not found.

Returned in case user is not authorized.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/{aid}/ids
