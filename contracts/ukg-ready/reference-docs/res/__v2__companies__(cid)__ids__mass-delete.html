Delete multiple documents

POST

Deletes one or more documents using a list of document IDs. This functionality is available for companies with the "Integrated Document Storage" marketplace product. If a document is associated with a module and has a linkedId, the user attempting to delete the document must have access to that module. For example, if one or more documents are linked with "Workers Claim", the user must have access to workers' claims to delete those documents.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

  • Content-Type
    string
    required

    Valid values: application/xml, text/xml, application/json

    Example: application/json

  • Content-Length
    integer
    required

Responses

Returns following values: 1. id: document id to be deleted. 2. status: returns status of OK, if deleted and failure if there was an issue with deleting the document(s). 3. user_messages: Returns a list of success messages for deleted document(s) and error messages for the document(s) that are not deleted.

If there are no any handlers for specified type or there were errors during validation.

Returned in case resource does not exist.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.
