Expense Item

PUT

Creates a new expense item belonging to the specified report. Please refer to the `Expense Type Metadata` endpoint on how to get the expense type metadata.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • report_id
    integer
    required
    Id of the expense report

Responses

Expense item was successfully created

Invalid request

No company access

Expense Report/Expense Type/Expense Profile Type was not found

Expense item failed to save

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/expense-tracking/report/{report_id}/item
