Collection

PUT

Update rate schedules collection

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • tid
    integer
    required
    Rate Table id.

Responses

Rate Schedules were successfully updated.

In case any error occurs during validation.

Definition

put {{ getUriPrefix() }}/v2/companies/{cid}/rates/tables/{tid}/schedules/collection
