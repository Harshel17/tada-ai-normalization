Snapshot

POST

Allows the caller to create a snapshot for the pay period.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • pay_period_id
    integer
    required
    Pay Period id

Responses

Snapshot is successfully created.

  • Location
    string
    required

    Example: <Address>/ta/rest/v2/companies/444545/pay-periods/55235777/action/snapshot/456444

    Location to delete the snapshot, if the snapshot was successfully created.

In case any error occurs during validation.

In case of security errors.

In case the service is unavailable.
