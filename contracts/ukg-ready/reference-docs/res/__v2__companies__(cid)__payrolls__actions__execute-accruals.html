Execute Accruals

POST

Performs the execute accruals process on the specified payrolls.

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • debug
    boolean

    Example: true

    Query parameter to indicate the debug mode.
  • run
    integer

    Example: 1

    Query parameter for the run mode.

Responses

Creation of execute accruals job successfully finished.

  • Location
    string
    required
    Location of the newly created job.

Definition

post {{ getUriPrefix() }}/v2/companies/{cid}/payrolls/actions/execute-accruals
