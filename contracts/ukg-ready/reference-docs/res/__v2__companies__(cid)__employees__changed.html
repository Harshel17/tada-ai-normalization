Changed employees

GET

Retrieves basic information about employee records that have been updated in a given time frame. The operation also includes links to information related to the employee that has changed within the same time frame. A single call to this operation includes changes to core employee fields (e.g., 'Firstname') as well as related resources (e.g., 'Pay Information'). The Employee operations use a separate security profile item to control access rights, located in the company security profile at: 1. `Modules -> REST API Resources -> Employees -> Changed View`. <b>Only the 'REST API RESOURCES' security profile item is considered by this REST API Resource.</b>

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
Query Parameters
  • since
    datetime

    Example: 2017-09-15T20:55:00Z

    Used to set reference date to determine changes, the value cannot be more than 31 days in the past. <br>Date should be expressed according to ISO 8601. <br>If the timezone is not provided or cannot be parsed the system will default to the timezone of the company. Default value is today minus 5 days.
  • terminatedEmployees
    boolean

    Example: false

    Used to set flag to filter out changed employee records which are already terminated with respect to reference date(Since). Default Value is true.
Header Parameters
  • Accept
    string

    Valid values: application/json, application/xml, text/xml

    Default: application/json

    Example: application/json

Responses

Returned in case resource does not exist.

Returned in case user is not authorized.

Returned in case user has no access to the resource.

Returned in the event that the call limit is exceeded. The application will be unavailable for subsequent calls for the duration specified by the X-CallLimit-TimeToWait header.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/employees/changed
