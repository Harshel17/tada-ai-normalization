Document Preview

GET

Retrieves the document preview metadata of a specified document. This functionality is available for companies with the "Integrated Document Storage" marketplace product.

  • v2

Parameters

Path Parameters
  • cid
    string
    required

    Example: 123456

    Company should be referenced via company id or company unique id or company short name using `|short_name` or `!short_name` format.
  • id
    integer
    required
    ID of uploaded document.
  • id
    integer
    required
    ID of uploaded document.

Responses

If there are no any handlers for specified type.

Definition

get {{ getUriPrefix() }}/v2/companies/{cid}/ids/{id}/preview
