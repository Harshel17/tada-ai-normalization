Contracts

POST

Creates employee contracts. If `working_days` is not specified, all days are marked as working. If `working_days` is an empty array, all days are marked as not working. `days_per_week` cannot be more than 7. `days_per_month` cannot be more than 31. `days_per_year` cannot be more than 366. The `fte` field is available for companies where the HR subsystem is not enabled. The value must be positive or zero.

PUT

Updates existing employee contracts. The operation uses the following fields to look up existing contracts: * id (contract_id or external_id) * start_date and end_date If a contract cannot be found using the provided fields, error code _13004_ is returned for the payload. `days_per_week` cannot be more than 7. `days_per_month` cannot be more than 31. `days_per_year` cannot be more than 366. The `fte` field is available for companies where the HR subsystem is not enabled. The value must be positive or zero.
