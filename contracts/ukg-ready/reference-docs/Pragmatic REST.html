## Operations that do not fit the REST paradigm
When an API operation cannot be described in terms of a CRUD (Create/Read/Update/Delete) operation on simple data, we include an additional verb as a URL subresource. This concept is known as "action as a resource."

Perhaps the most common use case involves the execution of data processing.

- The HTTP method is POST or PUT
- Within the URL, the resource or resource idenifier is followed by a verb subresource according to the following format:

    action(s)/{ACTION verb}

    **Note:** ACTION verbs include: submit, approve, reject, reopen and correct.

    Refer to the API Specifications for full details

    For example:

    `/v2/companies/<company_id>/timesheets/<timesheet_id>/action/submit`
    `/v2/companies/<company_id>/timesheets/<timesheet_id>/action/reject`

The body consists of a data items required to process the action.
